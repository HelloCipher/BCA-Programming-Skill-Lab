## ▶️ How to Compile and Run

Make sure GCC is installed and available in your terminal.

**Compile the program:**

```bash
gcc positive-number-calculator.c -o calculator
```

**Run on Windows PowerShell:**

```powershell
.\calculator.exe
```

Run these commands from the folder containing the C source file.
