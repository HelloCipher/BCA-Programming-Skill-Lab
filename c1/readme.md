# Second Number Positive — C Program

## Aim
Write a C program to input two integers and check whether the second number is greater than zero.

If the second number is positive, display the addition, multiplication, and subtraction of both numbers. Otherwise, display an error message.

## Concepts Used
- `scanf()` for user input
- `printf()` for output
- `if-else` conditional statement
- Arithmetic operators: `+`, `*`, `-`
- Relational operator: `>`

## Source Code
The program is available in `second_no_positive.c`.

## Example 1: Positive Second Number

Input:
- First number: 5
- Second number: 2

Output:
```text
Addition = 7
Multiplication = 10
Subtraction = 3
```

## Example 2: Second Number Is Zero

Input:
- First number: 5
- Second number: 0

Output:
```text
Error: Second number must be greater than zero.
```

## How to Compile and Run

Compile:
```bash
gcc second_no_positive.c -o second_no_positive
```

Run:
```bash
./second_no_positive
```

## Learning Outcome
This program demonstrates conditional statements, user input, and basic arithmetic operations in C.
